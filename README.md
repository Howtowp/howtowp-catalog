## این مخزن چیست؟

این ریپو **کاتالوگ عمومی** مجموعهٔ How to WP (چطور پرس) است: معرفی، نسخه، پیش‌نیازها و امکانات هر محصول، برای کاربران و برای عامل‌های هوش مصنوعی.

**کد افزونه‌ها و قالب‌ها اینجا نیست.** ریپوهای کد خصوصی‌اند. دسترسی از طریق [اشتراک کلاب در howtowp.ir](https://howtowp.ir) انجام می‌شود. خرید تکی هم در صورت ارائه از همان سایت ممکن است.

فهرست ماشین‌خوان در [catalog.json](https://raw.githubusercontent.com/howtowp/howtowp-catalog/main/catalog.json) و نقشهٔ مخصوص عامل‌ها در [llms.txt](llms.txt) است. قرارداد ساخت و به‌روزرسانی ریپوها در [STRUCTURE.md](STRUCTURE.md) آمده است.

مجموعهٔ فعلی: **28 افزونه** و **1 قالب**.

## نحوهٔ دسترسی

1. به [howtowp.ir](https://howtowp.ir) بروید و در کلاب عضو شوید (اشتراک ماهانه، تقریباً به‌قیمت یک افزونه).
2. تا وقتی اشتراک فعال است، به افزونه‌ها و قالب‌های مجموعه و به‌روزرسانی‌ها دسترسی دارید.
3. سورس خوانا و بدون قفل لایسنس است و روی سایت‌های خودتان نصب می‌شود.

پروفایل گیت‌هاب: [github.com/howtowp](https://github.com/howtowp)

## What this repository is

This is the **public catalog** for How to WP: names, versions, requirements, and features, for people and for AI agents.

**Plugin and theme source code is not stored here.** Code repositories are private. Access is through a [club subscription at howtowp.ir](https://howtowp.ir). Individual purchases may also be offered on the same site.

Machine-readable data lives in [catalog.json](https://raw.githubusercontent.com/howtowp/howtowp-catalog/main/catalog.json). The agent overview is [llms.txt](llms.txt). The standard for future repos and releases is [STRUCTURE.md](STRUCTURE.md).

The collection currently includes **28 plugins** and **1 theme**.

## How to get access

1. Go to [howtowp.ir](https://howtowp.ir) and join the club (a monthly subscription, priced like a single plugin).
2. While the subscription is active, you can use the collection and receive updates.
3. The source is readable and license-lock free, and you can install it on your own sites.

GitHub profile: [github.com/howtowp](https://github.com/howtowp)
