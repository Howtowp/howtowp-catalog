## About

**WooSync** is a plugin in the [How to WP](https://howtowp.ir) collection.

Peer-to-peer content and product sync across multiple WooCommerce sites with manual conflict resolution.

- **Type:** Plugin
- **Category:** WooCommerce & sales
- **Version:** 1.2.3

## Features

- Sync content and products across multiple WooCommerce sites.
- Peer-to-peer architecture with no external backend.
- HMAC-SHA256 authentication with anti-replay protection.
- Per-field sync toggles and an Action Scheduler-powered queue.
- Media de-duplication via SHA-256 and a manual conflict-resolution UI.

## Requirements

- **WordPress:** 6.0+
- **PHP:** 8.0+
