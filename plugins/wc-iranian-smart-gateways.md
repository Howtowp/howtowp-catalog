## About

**WooCommerce Smart Iranian Gateways** is a plugin in the [How to WP](https://howtowp.ir) collection.

Manages and auto-switches Iranian payment gateways (Mellat, Saman, Sadad, ZarinPal, and others) by amount, user role, and category, with a reverse proxy to work around blocked servers.

- **Type:** Plugin
- **Category:** Iranian payments & shipping
- **Version:** 2.5.0

## Features

- Supports Iranian gateways such as Mellat, Saman, Sadad, ZarinPal, Zibal, Asan Pardakht, IranKish, and Pasargad, plus custom API endpoints.
- A rules engine to auto-switch gateways by amount, user role, category, attributes, tags, city/province, and shipping method.
- Weighted round-robin traffic distribution between gateways.
- Automatic failover to a backup gateway on outage or timeout.
- A reverse-proxy option so bank requests can be sent from an Iran-based server.
- Duplicate a gateway into additional terminals with their own credentials.
