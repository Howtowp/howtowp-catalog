## About

**Dr. Debug - Smart Error Log Viewer** is a plugin in the [How to WP](https://howtowp.ir) collection.

Smart error log viewer for WordPress with fingerprint-based grouping, secret redaction, and a modern dashboard.

- **Type:** Plugin
- **Category:** SEO & tools
- **Version:** 1.0.0

## Features

- A smart error-log viewer with a Persian RTL dashboard.
- Groups identical errors with normalized fingerprints.
- Automatically redacts secrets such as passwords and tokens from messages and stack traces.
- Detects whether an error comes from a plugin, theme, or WordPress core, and classifies severity.
- Status tracking (new, seen, resolved, muted), an admin-bar indicator, scheduled cleanup, and debug.log rotation.
- An MU-plugin loader captures errors that occur before regular plugins load.
