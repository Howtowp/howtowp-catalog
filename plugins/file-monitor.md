## About

**File Monitor** is a plugin in the [How to WP](https://howtowp.ir) collection.

A modular plugin for monitoring file changes, with logging and Telegram notifications.

- **Type:** Plugin
- **Category:** Security & monitoring
- **Version:** 1.0.0

## Features

- Monitor WordPress file changes with scheduled scans.
- Store logs in the database and optionally in files.
- Send change reports to Telegram.
- Exclude paths such as uploads and cache.
- An admin screen for settings and log review.

## Requirements

- **WordPress:** 5.0+
- **PHP:** 7.4+
