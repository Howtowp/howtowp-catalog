## About

**Behpardakht Mellat for WooCommerce** is a plugin in the [How to WP](https://howtowp.ir) collection.

Bank Mellat (Behpardakht) IPG gateway with financial correctness first: verify/settle, reconciliation, locks, HPOS and Checkout Blocks.

- **Type:** Plugin
- **Category:** Iranian payments & shipping
- **Version:** 1.0.0-beta

## Features

- Bank Mellat (Behpardakht) IPG for WooCommerce.
- Separate Verify and Settle handling, with reversal attempts on failure.
- Callback locking to avoid duplicate processing, and amount checks before Settle.
- Cron reconciliation for incomplete payments.
- HPOS and Checkout Blocks compatible.
- Works without PHP SoapClient via an HTTP SOAP fallback.

## Requirements

- **WordPress:** 6.0+
- **PHP:** 7.4+
- **WooCommerce:** 8.0+
