## Features

- A professional WordPress form builder for the Iranian market.
- Drag-and-drop admin UI, conditional logic, Jalali dates, and a local captcha, as documented in the plugin readme.
- Iranian payment gateways and SMS providers, as documented in the plugin readme.
- Embed a form with the `[jazebe id="..."]` shortcode.
