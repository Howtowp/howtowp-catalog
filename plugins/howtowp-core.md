## About

**HowToWP Core** is a plugin in the [How to WP](https://howtowp.ir) collection.

Club membership, product Q&A, and feature requests for the HowToWP store.

- **Type:** Plugin
- **Category:** Theme & store
- **Version:** 1.0.0

## Features

- Club membership for access to HowToWP store products.
- Product Q&A and feature requests for logged-in users.
- Support tickets and checkout flows for club plans.
- Global product add-ons (for example warranty or setup) with a per-product price.

## Requirements

- **WordPress:** 6.0+
- **PHP:** 7.4+

## Version

Current version in the product header: **1.0.0**.
