## About

**DrDebug Syncer** is a plugin in the [How to WP](https://howtowp.ir) collection.

Offload WordPress media (images, video, audio, and documents) to cloud storage. ParsPack S3-compatible provider with extensible architecture.

- **Type:** Plugin
- **Category:** SEO & tools
- **Version:** 1.0.2

## Features

- Offload WordPress media (images, video, audio, PDFs, and other attachments) to the cloud.
- ParsPack S3-compatible provider.
- Rewrites attachment URLs so files are served from the cloud.
- Extensible provider architecture. PHP dependencies are bundled with the plugin.

## Requirements

- **WordPress:** 5.9+
- **PHP:** 8.1+
